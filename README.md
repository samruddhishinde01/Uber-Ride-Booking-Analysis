# Uber Ride Booking Analysis

## Project Overview

Uber Ride Booking Analysis is a data analytics project based on ride booking data.

The project analyzes booking performance, customer and driver cancellations, revenue, ride distance, ratings, payment methods, and high-demand locations.

Excel, SQL, Python, and Power BI were used to clean, analyze, and visualize the data.

---

## Objective

The main objective of this project is to:

- Analyze overall ride booking performance
- Understand booking status and ride trends
- Analyze customer and driver cancellations
- Identify common cancellation reasons
- Analyze revenue by vehicle type
- Identify popular pickup and drop locations
- Analyze payment methods and ratings
- Create an interactive Power BI dashboard
- Generate useful business insights

---

## Tools & Technologies

- **Excel** – Data cleaning and basic analysis
- **SQL (MySQL)** – Data querying and analysis
- **Python (Pandas)** – Data analysis
- **Power BI** – Interactive dashboard and data visualization

---

## Dataset

The dataset contains **150,000 ride booking records and 21 columns**.

Important columns include:

- Booking ID
- Booking Status
- Customer ID
- Vehicle Type
- Pickup Location
- Drop Location
- Avg VTAT
- Avg CTAT
- Customer and Driver Cancellation Details
- Incomplete Ride Details
- Booking Value
- Ride Distance
- Driver Ratings
- Customer Rating
- Payment Method

---

## Data Cleaning

The dataset was cleaned before analysis.

The following tasks were performed:

- Formatted Date and Time columns
- Checked for duplicate records
- Handled NULL values
- Replaced NULL values in cancellation and incomplete ride fields where appropriate
- Kept NULL values for fields where missing values were meaningful
- Corrected data types
- Prepared the dataset for analysis
